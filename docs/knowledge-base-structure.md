# Structure cible de la base de connaissances RH

Chaque policy doit pouvoir être décrite par des métadonnées, indépendamment de sa source SharePoint. L'objectif est de rendre possible le filtrage des droits et la recherche documentaire sans exposer des documents hors périmètre.

| Champ | Rôle |
|---|---|
| Identifiant de policy | Référence stable du document |
| Titre | Identification lisible |
| Pays / entité | Détermine le périmètre géographique |
| Population ou groupe autorisé | Détermine qui peut utiliser le document |
| Langue | Indique la langue de la policy |
| Thème RH | Facilite la classification et le suivi |
| Lien ou identifiant SharePoint | Conserve la source officielle |
| Date de mise à jour | Permet de repérer une policy obsolète |
| Statut | Brouillon, validée, archivée |
| Contenu découpé en passages | Unité utilisée pour la recherche et la citation |

Les policies restent la source de vérité dans SharePoint. Le prototype ne remplace pas leur gouvernance documentaire.
